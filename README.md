# Tasking

Менеджер задач для команды: доска, список, структура, Гант и календарь,
«Мои задачи», «Входящие», чат с файлами в каждой задаче, согласования.
Статическое веб-приложение без сборки (обычные `<script>`, открывается и
через `file://`) с сервером на Google Apps Script поверх Google Таблицы.

Боевой адрес: https://gish4ik1985-crypto.github.io/tasking/

## Устройство

| Файл | Что делает |
|---|---|
| `index.html`, `style.css` | разметка и стили |
| `js/app.js` | всё приложение: виды, окно задачи, экраны |
| `js/sync.js` | мост к серверу: очередь отправки, пакетное сохранение, опрос |
| `js/auth.js` | вход, профиль, мгновенный старт из кэша |
| `js/admin.js` | панель администратора |
| `gas/Code.gs` | сервер (Google Apps Script) |
| `dev/gas-emulator.js` | эмулятор Apps Script для тестов и локальной разработки |

Интерфейс работает с локальной копией данных (правки видны мгновенно),
`js/sync.js` отправляет изменения на сервер в фоне и раз в 20 секунд
спрашивает, нет ли нового от коллег. Статус сохранения — внизу боковой панели.

## Обновление сервера (Code.gs)

1. Откройте таблицу → Расширения → Apps Script, замените код содержимым `gas/Code.gs`.
2. Выберите функцию `setup` и нажмите ▶ Run — Google спросит разрешения
   (Таблица, Диск — для файлов в чате, Почта — для уведомлений). Подтвердите.
3. Deploy → Manage deployments → ✏ → Version: New version → Deploy.

Недостающие листы и столбцы сервер дописывает сам. Клиент совместим и со
старой, и с новой версией сервера — сайт можно обновлять раньше сервера.

Вместо копирования можно выкладывать через [clasp](https://github.com/google/clasp):
`npm i -g @google/clasp`, `clasp login`, затем в папке `gas/` создать
`.clasp.json` с `{"scriptId": "<ID скрипта из настроек проекта Apps Script>"}`
и выполнять `clasp push` (+ новый деплой, как в шаге 3).

## Администрирование

Администратор — строка в листе Users со столбцом `isAdmin` = TRUE (ставится
только вручную в таблице). В профиле у него появляется «Управление
пользователями»: создание аккаунтов, смена пароля (выкидывает человека со
всех устройств), удаление, и переключатель открытой регистрации —
рекомендуем её выключить и заводить людей самим.

## Разработка

```bash
npm install
npm test          # 77 тестов: логика интерфейса, сервер на эмуляторе, синхронизация
npm run lint
npm run dev:api   # локальный сервер на эмуляторе, порт 8935
```

Чтобы открыть приложение с локальным сервером вместо боевой таблицы,
запустите статический сервер (например, `python -m http.server 8934`) и в
консоли браузера на http://localhost:8934 выполните:

```js
localStorage.setItem("tasking-api-url", "http://localhost:8935");
localStorage.setItem("tasking-auth-v1", JSON.stringify(await (await fetch("http://localhost:8935/dev-session?user=anna")).json()));
location.reload();
```

Тестовые пользователи эмулятора: `anna` (администратор), `boris`, `vera`.
Данные эмулятора живут в памяти и пропадают при перезапуске.

`improvements.html` — план улучшений от 3 сентября 2026 (исторический),
актуальный разбор — `аудит от opus 5.5.html`.
